# 🌐 HTML5 Semantic Structure & Accessibility Portfolio

An accessible, SEO-optimized, multi-page personal portfolio template built strictly with modern **HTML5 semantic standards** and **WCAG 2.1 AA accessibility guidelines**. 

This repository provides a solid baseline for web developers aiming to achieve a **100/100 score on Google Lighthouse Accessibility & SEO audits**.

---

## ✨ Key Features

* 🏗️ **Semantic HTML5 Architecture:** Built using clean landmark elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* ♿ **WCAG 2.1 AA Compliant:** Features a keyboard-accessible skip link, clear visual focus indicators (`:focus-visible`), and explicit ARIA labels/roles.
* 📝 **Accessible Contact Form:** Full tab navigation, explicit `<label>` bindings, hint text (`aria-describedby`), and required field indicators.
* 🔍 **SEO & Open Graph Ready:** Includes page-specific meta descriptions, canonical links, social metadata, and clean heading hierarchies.
* 🎨 **Modern & Responsive UI:** Styled with CSS variables, fluid typography (`clamp()`), flexbox/grid layouts, and sleek card components.
